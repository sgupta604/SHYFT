# Research: commons-app

**Date:** 2026-06-05T10:03:20 | **Status:** research-complete

## Goal
Scaffold the SHYFT pnpm/Turborepo monorepo and build Commons — the Shyft employee mobile app — as an Expo (managed, Expo Go-compatible) React Native app at `packages/mobile`, pixel-faithful to the Clarity prototype, demoable on a physical iPhone via Expo Go **today**.

Decisions in `docs/DECISIONS.md` are final: Expo + expo-router + Zustand + TS strict, jest-expo + RNTL, lucide-react-native, @expo-google-fonts (Sora/Inter/JetBrains Mono), in-memory mock data only, feature-module plugin architecture.

### Technical
- [ ] TR1: pnpm workspace + Turborepo at repo root; app at `packages/mobile/`; root `.npmrc` with `node-linker=hoisted` **before first install** (see Risks)
- [ ] TR2: **Expo SDK 54** (not 56) — App Store Expo Go supports only SDK 54 as of May 2026; SDK 55/56 Expo Go is TestFlight-only. `create-expo-app` (SDK 56 era) prompts for "App Store compatibility" — choose it, or use `--template default@sdk-54`
- [ ] TR3: expo-router file-based nav: `app/_layout.tsx` (fonts + root Stack) → `app/(tabs)/_layout.tsx` (5 tabs) → tab routes; full-screen overlays (StipendDetail, Profile, Onboarding) as stack pushes `stipend/[id]`, `person/[id]`, `onboarding`; routes are thin — all UI in `features/`
- [ ] TR4: Plugin architecture: `features/{today,events,you,people,more,onboarding}/` self-contained; each exports a feature manifest (id, tab label/icon, screen) registered in `lib/registry.ts`; tab layout reads the registry. **No cross-feature imports** — cross-feature navigation only via route paths (e.g. announcement deep-link → `/(tabs)/you`), shared state only via `lib/stores`
- [ ] TR5: Zustand stores in `lib/stores/`: events (RSVP math), kudos (cheer), onboarding (checklist toggle); static data in `lib/data/` typed modules. Stores = single source of truth so Today/Events/You/sheets all reflect the same RSVP state
- [ ] TR6: Theme module `lib/theme/`: tokens ported from `colors_and_type.css` (see mapping below); no StyleSheet color literals in features
- [ ] TR7: Fonts via `@expo-google-fonts/sora` (400-700), `/inter`, `/jetbrains-mono` + `useFonts` in root layout, hold splash until loaded (`expo-splash-screen`)
- [ ] TR8: Icons via `lucide-react-native` + `react-native-svg` (installed with `npx expo install` — bundled in Expo Go SDK 54)
- [ ] TR9: Safe areas via `react-native-safe-area-context` (replaces prototype's hardcoded `padding-top: 56px` / `padding-bottom: 26px`)
- [ ] TR10: jest-expo + RNTL: unit tests for store logic (RSVP ±1 + toggle, cheer toggle, checklist toggle/count, stipend remaining/pct/low-balance calc) + render smoke test per screen
- [ ] TR11: Expo Go-compatible only: no native modules, no @gorhom/bottom-sheet-style native libs needed (RN `Modal` + `Animated`), no AsyncStorage

### Constraints
- Must demo on physical iPhone via Expo Go TODAY (same Wi-Fi; Node 25.3.0, pnpm 9.15.9, npx for expo CLI)
- Pixel-faithful to prototype; recreate, don't copy prototype internals
- Clarity rules: sentence case, no emoji outside category tags, flat surfaces + hairlines, animations 120–220ms ease-out only, brights never in chrome
- No backend, no persistence, no E2E today

## Code Examples from Spec (high-value for plan)

**RSVP toggle (App.jsx:44-45)** — port verbatim into events store:
```js
e.rsvp === 'going' ? { rsvp: null, going: going - 1 } : { rsvp: 'going', going: going + 1 }
```
**Capacity bar:** `pct = Math.round((going / capacity) * 100)` — 5px track `--bg-sunken`, fill `--accent`, radius 99.
**Stipend math (YouScreen.jsx:8-10):** `remaining = total - used`; `pct = Math.min(100, Math.round(used/total*100))`; `low = remaining <= total * 0.2` → orange reset note " · use it or lose it". Bar fill = `{tone}-700` on cards, `{tone}-300` on dark hero.
**Avatar tone (Primitives.jsx:33-39):** deterministic hash `h = h*31 + charCode >>> 0` over 8-color array; initials = first letters of first 2 words.
**Pill tones (Primitives.jsx:53-60):** blue/green/orange/pink/purple/neutral → [bg, fg, dot] triples. Receipt status: Pending=orange, Approved=blue, Reimbursed=green. Kudos values: Customer obsession=blue, Ownership=green, Craft=purple, Team=orange.
**Sheet animation (commons.css:151-166):** scrim fade 180ms; sheet `translateY(18px)→0` + opacity .6→1, 220ms `cubic-bezier(.22,1,.36,1)`; max-height 88%; radius 28px top.
**Header map (App.jsx:51-57)** — exact per-tab titles/subtitles/mark/search flags.

## Token → RN Theme Mapping
- Color scales + semantic tokens (colors_and_type.css:12-107) → `lib/theme/colors.ts` const objects (blue25…blue900, charcoal25…900, brights 300/500/700, semantic bg/bgElev/border/text/accent/etc). Light theme only today (dark block exists in tokens; defer).
- Spacing `--s-1…--s-16` → `space = {1:4, 2:8, 3:12, 4:16, 5:20, 6:24, 8:32, 12:48, 16:64}`; radii `{sm:8, md:10, lg:14, xl:20, '2xl':28, full:9999}`.
- Type classes (lines 139-150) → `lib/theme/type.ts` TextStyle objects; CSS weight→font-file mapping (e.g. `600 Sora` → `fontFamily: 'Sora_600SemiBold'` — RN selects weight by family name, not fontWeight). letterSpacing em→px (`-0.02em @ 40px` → `-0.8`). Tabular numerics: `fontVariant: ['tabular-nums']` (and JetBrains Mono for `c-num`).
- Shadows: design is deliberately flat — borders do the work; map `shadow-1` to a minimal iOS shadow or omit; card = white bg + 1px `border` hairline + radius 20.
- CSS-isms needing RN translation: `-webkit-line-clamp:2` → `numberOfLines={2}`; `%`-width bar fills work in RN (`width: \`${pct}%\``) inside overflow-hidden track; negative-margin avatar stack ports directly; tab-bar `backdrop-filter` blur → recommend solid `rgba(255,255,255,0.96)` (flat register; avoids expo-blur dependency — expo-blur IS in Expo Go if pixel-fidelity demands it); `:active` scale(.992) → `Pressable` style fn or skip (press = settle, no bounce per Clarity).

## Patterns to Follow
- Greenfield, but conventions are fixed by CLAUDE.md + DECISIONS.md: routes thin (`app/` = routing only), logic in `lib/`, UI in `components/`/`features/`; Zustand = single source of truth; one component per file; no barrel files; `@/` alias; commits `feat(mobile):`
- Prototype's data-shape and state logic (App.jsx) port near-verbatim into stores — keep the same field names (`rsvp`, `going`, `cheered`, `done`) so the data layer matches the design source
- Clarity motion register: 120–220ms ease-out, fades + small translates, no bounce/scale-up
- Sheet shell pattern from Sheets.jsx:5-22 (grab handle, optional title row, scrim) as one shared `<Sheet>` component; feature-specific sheet bodies live in their feature module

## Patterns to Avoid
- Prototype internals: `window.*` globals, `Object.assign(window,…)`, CDN Lucide `<i data-lucide>` polling — RN uses direct `lucide-react-native` component imports
- Native sheet libs (@gorhom/bottom-sheet w/ custom config beyond Expo Go) — use RN `Modal` (transparent) + `Animated` translateY/opacity with `useNativeDriver: true`
- Hardcoded status-bar/home-indicator paddings (56/26px) — use safe-area insets
- Cross-feature imports (plugin requirement); raw hex in feature code (theme tokens only)
- Hot-linking `portal.internal.shyftsolutions.io` for the S2 mark
- ios-frame.jsx — irrelevant on a real device, do not port

| **Time pressure** (one day, ~10 screens/sheets) | H | Build in demo-priority order (You→StipendDetail, Events RSVP, More→Onboarding, then Today, People, sheets). Cut list ready: search behavior, Past filter logic, dark theme, tab-bar blur, drag-to-dismiss sheets |
| Sheet animation jank / gesture complexity | M | RN Modal + Animated (native driver), tap-scrim-to-close only — no pan gesture today. Matches prototype (no drag there either) |
| `lucide-react-native` icon-name gaps (`volleyball`, `glass-water`, `square-parking` are newer glyphs) or missing `react-native-svg` | M | `npx expo install react-native-svg`; verify all ~50 icon names against installed lucide version during theme task; one-line substitutions if missing |
| Same-Wi-Fi LAN connection fails (corp network isolation) | M | Fallback `npx expo start --tunnel`; USB not an option in Expo Go — verify connectivity at first smoke test |
| jest-expo + pnpm transform issues | M | jest-expo preset + `transformIgnorePatterns` allowlist; hoisted node_modules avoids most of it |
| Capacity/stipend bar math edge cases (0 used, full, >100%) | L | Already clamped in prototype (`Math.min(100,…)`); unit-test these exact functions |

## Recommended Approach
Scaffold bottom-up with an on-device checkpoint first: (1) monorepo + `.npmrc` + Expo SDK 54 app, prove blank app loads in Expo Go on the iPhone before anything else; (2) theme tokens + fonts + shared primitives (Icon/Avatar/Pill/Button/Card/Sheet/Segmented/StatusBanner/Chrome); (3) typed data + Zustand stores with unit tests (the three demo-critical state machines: RSVP, checklist, cheer — plus stipend math); (4) expo-router shell with feature registry, then screens in demo-priority order (You + StipendDetail → Events → More + Onboarding → Today + sheets → People + Profile); (5) smoke tests + on-device polish pass. Sheets via one shared RN-Modal-based `<Sheet>` with Animated rise/fade.

## Scope: L
~35–40 new files (monorepo config, theme, 3 stores + data, ~12 shared components, 6 feature modules with ~10 screens/sheets, route files, ~10 test files), but zero integration risk (no backend, mock data, single platform target) and the prototype specifies every pixel and all state logic. Large-but-mechanical; fits one intense day if the device checkpoint passes early.
