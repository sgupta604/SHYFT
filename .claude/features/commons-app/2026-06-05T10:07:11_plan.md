# Plan: commons-app

**Date:** 2026-06-05T10:07:11 | **Based on:** 2026-06-05T10:03:20_research.md | **Branch:** feat/commons-app

## Architecture

### Summary
Greenfield: scaffold the SHYFT pnpm/Turborepo monorepo and build Commons as an Expo SDK 54 (managed, Expo Go-compatible) React Native app at `packages/mobile`. expo-router provides the shell (root Stack → 5-tab layout → full-screen pushes for StipendDetail/Profile/Onboarding); routes are thin and render screens from self-contained `features/<name>/` modules registered through `lib/registry.ts` (plugin-ready, no cross-feature imports). Zustand stores in `lib/stores/` own all mutable state (RSVP, cheer, onboarding checklist) over typed in-memory mock data in `lib/data/`; theme tokens in `lib/theme/` port `colors_and_type.css`. No backend, no persistence.

### Data Flow
```
app/_layout.tsx (fonts + splash hold + root Stack)
└── app/(tabs)/_layout.tsx ──reads── lib/registry.ts ──lists── features/*/manifest.ts
    ├── (tabs)/{index,events,you,people,more}.tsx   (thin: render feature screen)
    ├── stipend/[id].tsx · person/[id].tsx · onboarding.tsx   (full-screen pushes)
    │
    features/<tab>/Screen + feature-owned cards/sheets
    ├──→ components/* (shared primitives: Sheet, Pill, Avatar, EventCard, …)
    ├──→ lib/stores/{events,kudos,onboarding}  (Zustand — single source of truth)
    │         └──seeded from── lib/data/* (typed mock data, ported 1:1 from data.jsx)
    └──→ lib/theme/{colors,spacing,type}  (no raw hex in features)

Cross-feature navigation by route path only (announcement CTA → router.push('/(tabs)/you'))
```

- No backend (`packages/api` stays dormant), no auth, no persistence/AsyncStorage — state resets on reload by design
- No dark theme (tokens exist; deferred), no tab-bar blur (solid `rgba(255,255,255,0.96)`), no drag-to-dismiss sheets (scrim/X only)
- Search is visual-only; 'Past' events filter shows all events (faithful prototype port)
- Non-functional taps stay no-ops: Submit receipt, Message, Give kudos, Open in Slack, perks, handbook, swag/settings/FAQ rows
- No Maestro/Playwright E2E, no EAS standalone builds, no push notifications, no plugin SDK runtime (architecture is plugin-*ready* only)
- No `ios-frame.jsx` port; no Android-specific polish (cross-platform RN, but today's target is the iPhone demo)

- **Contract-first registry:** `lib/registry.ts` + all 5 manifests + placeholder screens land in Stream 2 and are then FROZEN — parallel feature streams never touch shared files, eliminating worktree merge conflicts
- **EventCard promoted to `components/`** (not `features/events/`) because Today renders it too — preserves the no-cross-feature-imports rule; same for NotificationsSheet (chrome-level)
- **Sheets = RN `Modal` + `Animated` (native driver)**, no native bottom-sheet libs — Expo Go-safe, matches prototype (no drag there either)
- **Stipend math as pure functions** in `lib/utils/stipend.ts` — unit-testable independent of UI, future API seam
- **Solid tab bar instead of backdrop blur** — Clarity reserves blur for overlays; avoids expo-blur dependency
- **Prototype field names kept** (`rsvp`, `going`, `cheered`, `done`) so the data layer matches the design source 1:1

## Notes for Implementer
- `.npmrc` MUST exist before the first `pnpm install` — hoisting cannot be retrofitted cheaply; delete `node_modules` and reinstall if ordering slips
- RN selects font weight by family name: use `fontFamily: 'Sora_600SemiBold'`, never `fontWeight` with a custom font; letterSpacing converts em→px against the fontSize (`-0.02em @ 40px` → `-0.8`)
- RSVP logic ports verbatim from App.jsx:44-45: `e.rsvp === 'going' ? { rsvp: null, going: going - 1 } : { rsvp: 'going', going: going + 1 }`
- Stipend bars: `{tone}-700` fill on light cards, `{tone}-300` on the charcoal hero
- Avatar tone hash: `h = h*31 + charCode >>> 0` over the 8-color array; initials = first letters of first 2 words
- Audit Lucide names early (Task 2.1): `volleyball`, `glass-water`, `square-parking` may be missing in the installed version — substitute one-liners, don't upgrade the package
- `-webkit-line-clamp:2` → `numberOfLines={2}`; %-width bar fills work in RN inside an overflow-hidden track; negative-margin avatar stacks port directly
- `:active scale(.992)` → skip or `Pressable` style fn; Clarity motion = 120–220ms ease-out, fades + small translates, never bounce
- jest-expo + pnpm: expect to extend `transformIgnorePatterns`; hoisted node_modules avoids most resolution pain
- If LAN connect fails on corp Wi-Fi: `npx expo start --tunnel` (USB is not an option in Expo Go)
- S2 mark: bundle the local PNG only — the portal URL resolves exclusively on Shyft's network
